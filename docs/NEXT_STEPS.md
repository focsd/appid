# Suggested next steps

Potential v0.2 additions:

- searchable list of launcher apps to fill package ID automatically;
- app icon capture / optional neutral icon generation;
- saved placeholder profiles;
- “restore checklist” for each replaced app;
- configurable message/subtitle such as “What did you intend to do?”;
- optional delay/countdown before Close;
- build history and APK path list;
- signing-key backup/export helper;
- direct PackageInstaller integration after Termux finishes building;
- Termux command-result receiver so AppId can show build logs without switching apps;
- optional alternative package ID mode for testing placeholders without uninstalling originals.
